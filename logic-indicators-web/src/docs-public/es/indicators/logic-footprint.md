# Logic Footprint

> **Resumen público** — para acceder al manual técnico completo (todos los parámetros, opciones de configuración y mejores prácticas), [iniciá sesión en tu cuenta](/login?next=/dashboard/docs/indicators/logic-footprint).

## ¿Qué es?

El indicador **Logic Footprint** transforma cada vela de tu gráfico en un mapa detallado del volumen ejecutado. En lugar de ver solo Apertura, Máximo, Mínimo y Cierre, ves cuántos contratos se operaron en cada nivel de precio dentro de esa barra — y si los compradores o vendedores fueron los agresivos en cada tick.

Es la base del análisis de Order Flow: te permite detectar absorción, agotamiento e iniciativa agresiva que son completamente invisibles en un gráfico de velas estándar.

## Características principales

- **Volumen + Delta por nivel de precio** dentro de cada vela
- **Visualización de imbalance Bid/Ask** con colores de mapa de calor
- **Imbalances apilados** para detectar zonas de absorción institucional
- **Marcadores de Unfinished Business (UBA / DNBA)** para setups de continuación
- **Filtros de volumen** para ocultar el ruido de baja actividad

## ¿Para quién es?

Para day traders, scalpers y entusiastas del order flow que necesitan leer el proceso de subasta a nivel de tick en lugar de adivinar por la forma de las velas.
