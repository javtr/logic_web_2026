# Algorithms

> **Resumen público** — para acceder al manual técnico completo, [iniciá sesión en tu cuenta](/login?next=/dashboard/docs/indicators/logic-algorithms).

## ¿Qué es?

La suite de **Algorithms** es una colección de motores de señales automatizadas que detectan condiciones específicas de order flow y disparan alertas visuales y sonoras directamente en tu gráfico. En lugar de mirar decenas de indicadores y tratar de interpretarlos en tiempo real, los algoritmos hacen la interpretación por vos y te avisan cuando está pasando algo interesante.

Cada algoritmo está diseñado para detectar una condición particular del mercado — absorción, agotamiento, imbalances apilados, divergencias de delta, y más — para que vos te enfoques en la ejecución en lugar del análisis.

## Características principales

- **Motores de señales preconfigurados** para los setups de order flow más comunes
- **Alertas visuales y sonoras en tiempo real** para que no te pierdas ningún setup
- **Umbrales personalizables** para cada algoritmo
- **Análisis multi-timeframe** integrado
- **Vista de backtest histórico** para ver cómo se habrían comportado los algoritmos

## ¿Para quién es?

Para traders que quieren que la parte pesada de la detección de patrones se maneje de forma automática y prefieren recibir señales accionables en lugar de interpretar manualmente los datos crudos de order flow.
