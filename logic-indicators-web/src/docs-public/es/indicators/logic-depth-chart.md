# Logic Depth Chart

> **Resumen público** — para acceder al manual técnico completo, [iniciá sesión en tu cuenta](/login?next=/dashboard/docs/indicators/logic-depth-chart).

## ¿Qué es?

El indicador **Logic Depth Chart** es el mapa de liquidez institucional de Nivel 2 integrado directamente en la acción del precio para NinjaTrader 8.

Lleva tu análisis de Order Flow al siguiente nivel descubriendo las intenciones de los grandes participantes antes de que el precio se mueva. Logic Depth Chart rastrea y dibuja el histórico de liquidez pasiva directamente detrás y sobre cada vela de tu gráfico, acompañado de un perfil visual del libro de órdenes en vivo.

## Características principales

- **Rastreo de Liquidez Pasiva:** Dibuja el histórico de liquidez en tiempo real directamente sobre el gráfico.
- **Perfil de Libro de Órdenes en Vivo:** Visualiza los contratos institucionales colocados, modificados o absorbidos.
- **Integración Nativa:** Optimizado para operar con cero latencia en NinjaTrader 8.
