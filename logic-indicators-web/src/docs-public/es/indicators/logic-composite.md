# Logic Composite

> **Resumen público** — para acceder al manual técnico completo, [iniciá sesión en tu cuenta](/login?next=/dashboard/docs/indicators/logic-composite).

## ¿Qué es?

El indicador **Logic Composite** está construido para el análisis macro-estructural. Mientras que el Logic Profile estándar es perfecto para desgloses sesión por sesión, el Composite está diseñado para analizar bloques masivos de datos históricos o áreas específicas de consolidación trazadas manualmente.

Construí "Perfiles Compuestos" que abarcan múltiples días, semanas o meses, y anclalos a un lado de la pantalla para identificar zonas históricas mayores de soporte y resistencia que los perfiles intradiarios estándar simplemente no pueden ver.

## Características principales

- **Columnas de datos macro** que abarcan semanas o meses de historia
- **Anclaje fijo a la pantalla** al borde Izquierdo o Derecho, que se mantiene visible mientras hacés scroll
- **Modo de dibujo manual** (similar a un retroceso de Fibonacci) para análisis personalizado de swings
- **Área de Valor y POC** calculados sobre datasets macro como fronteras históricas mayores
- **Panel de Métricas** que resume el Volumen total, Delta y Rango de toda la estructura compuesta

## ¿Para quién es?

Para traders de posición y analistas macro que necesitan identificar los niveles históricos dominantes donde el mercado ha defendido sus posiciones a lo largo de semanas o meses.
