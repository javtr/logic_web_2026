# Logic Depth Live

> **Public overview** — for the complete technical manual, please [sign in to your account](/login?next=/dashboard/docs/indicators/logic-depth-live).

## What is it?

The **Logic Depth Live** indicator transforms your NinjaTrader 8 charts into a powerful interactive heatmap, allowing you to clearly see where institutional buy and sell orders are concentrated before price reaches them.

## Key Features

- **Interactive Heatmap:** Discover true market intent and detect liquidity traps.
- **Intelligent Volume Bubbles:** Analyze aggressive trades in real time.
- **Live Depth Panel:** Built to anticipate price reversals and confirm breakouts with confidence.
