# Logic Depth Live

> If you haven't installed the Logic Indicators suite yet, please check the [Installation Guide](/docs/installation) first.

The **Logic Depth Live** indicator transforms your NinjaTrader 8 charts into a powerful interactive heatmap, allowing you to clearly see where institutional buy and sell orders are concentrated before price reaches them.

## Key Features

1. **Interactive Heatmap:** Discover true market intent and detect liquidity traps.
2. **Intelligent Volume Bubbles:** Analyze aggressive trades in real time.
3. **Live Depth Panel:** Built to anticipate price reversals and confirm breakouts with confidence.
