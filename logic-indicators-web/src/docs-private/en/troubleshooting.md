## Indicators not showing up

1. Make sure NinjaTrader 8 is fully closed before installing
2. Run the installer as Administrator
3. Check the Indicators list in NinjaTrader 8 — they should be under "Logic Indicators"

## Performance issues

- Reduce the number of price rows in footprint indicators
- Disable heatmap mode for less GPU usage
- Close other heavy applications during market hours

## License activation problems

- Verify your machine ID matches the one in your account
- Make sure you have an active internet connection
- Contact support if the issue persists
