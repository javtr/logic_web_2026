# Logic Depth Chart

> Si todavía no instalaste la suite de Logic Indicators, consultá la [Guía de instalación](/docs/installation) primero.

El indicador **Logic Depth Chart** es el mapa de liquidez institucional de Nivel 2 integrado directamente en la acción del precio para NinjaTrader 8.

Lleva tu análisis de Order Flow al siguiente nivel descubriendo las intenciones de los grandes participantes antes de que el precio se mueva. Logic Depth Chart para NinjaTrader 8 rastrea y dibuja el histórico de liquidez pasiva directamente detrás y sobre cada vela de tu gráfico, acompañado de un perfil visual del libro de órdenes en vivo.

## Componentes Principales

1. **Rastreo de Liquidez Pasiva:** Dibuja el histórico de liquidez en tiempo real directamente sobre el gráfico.
2. **Perfil de Libro de Órdenes en Vivo:** Visualiza los contratos institucionales colocados, modificados o absorbidos.
3. **Integración Nativa:** Cero latencia y máxima optimización en NinjaTrader 8.
