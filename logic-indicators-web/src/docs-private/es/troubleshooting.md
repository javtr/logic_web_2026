## Los indicadores no aparecen

1. Asegúrate de que NinjaTrader 8 esté cerrado antes de instalar
2. Ejecuta el instalador como Administrador
3. Busca en la lista de Indicadores — deberían estar bajo "Logic Indicators"

## Problemas de performance

- Reduce el número de filas de precio en los footprints
- Desactiva el modo heatmap para menos uso de GPU
- Cierra otras aplicaciones pesadas durante horario de mercado

## Problemas de activación

- Verifica que tu Machine ID coincida con el de tu cuenta
- Asegúrate de tener conexión a internet
- Contáctanos si el problema persiste

## Soporte

Si tu problema no está cubierto aquí, contáctanos desde la página de [Contacto](/contact).
