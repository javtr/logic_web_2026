## Los indicadores no aparecen

1. Asegurate de que NinjaTrader 8 esté cerrado antes de instalar
2. Ejecutá el instalador como Administrador
3. Buscá en la lista de Indicadores — deberían estar bajo "Logic Indicators"

## Problemas de performance

- Reducí el número de filas de precio en los footprints
- Desactivá el modo heatmap para menos uso de GPU
- Cerrá otras aplicaciones pesadas durante horario de mercado

## Problemas de activación

- Verificá que tu Machine ID coincida con el de tu cuenta
- Asegurate de tener conexión a internet
- Contactanos si el problema persiste

## Soporte

Si tu problema no está cubierto acá, contactanos desde la página de [Contacto](/contact).
