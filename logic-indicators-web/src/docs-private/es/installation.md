# Instalación

> Placeholder. Contenido real próximamente.

## Requisitos

- NinjaTrader 8 (última versión)
- Windows 10 u 11
- Conexión a internet para activar la licencia
- 200 MB de espacio libre

## Pasos

1. Descargá el instalador desde tu cuenta
2. Ejecutalo como Administrador
3. Reiniciá NinjaTrader 8
4. Aplicá tu clave de licencia
5. Verificá que los indicadores aparezcan en la lista

## Problemas de instalación

Si los indicadores no aparecen, consultá la guía de [Solución de problemas](/docs/troubleshooting).
