# Logic Footprint

> Placeholder. Contenido real próximamente.

El indicador Logic Footprint te da una vista detallada de la distribución de volumen dentro de cada vela, permitiendo identificar absorción, agotamiento y compras/ventas agresivas.

## Características principales

- Modos de visualización cluster y heatmap
- Cálculo de delta en tiempo real
- Número de filas de precio configurable
- Resaltado de imbalances y zonas de absorción

## Configuración

| Setting | Default | Description |
|---|---|---|
| Mode | Cluster | Modo de visualización |
| Rows | 24 | Filas de precio por vela |
| Delta | Both | Mostrar bid, ask o ambos |

## Tips

- Empezá con los presets por defecto
- Usá el Data Box para métricas rápidas
- Combiná con Volume Profile para contexto de subasta
