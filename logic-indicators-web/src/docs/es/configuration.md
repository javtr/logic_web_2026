## Presets globales

Los presets son configuraciones guardadas que se pueden aplicar a todos los indicadores. Usalos para cambiar entre estilos de trading (scalping, day trading, swing) al instante.

## Tema

El suite soporta temas claro y oscuro, igualando a NinjaTrader 8.

## Performance

El suite está diseñado para correr con latencia cero incluso en momentos de alta volatilidad.
