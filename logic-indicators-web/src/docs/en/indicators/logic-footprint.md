# Logic Footprint

> Placeholder. Real content coming soon.

The Logic Footprint indicator provides a detailed view of volume distribution within each price candle, allowing traders to identify absorption, exhaustion, and aggressive buying or selling.

## Key features

- Cluster and heatmap visualization modes
- Real-time delta calculation
- Configurable number of price rows
- Highlight imbalances and absorption zones

## Configuration

| Setting | Default | Description |
|---|---|---|
| Mode | Cluster | Visualization mode (cluster or heatmap) |
| Rows | 24 | Number of price rows per candle |
| Delta display | Both | Show bid, ask, or both |

## Tips

- Start with default presets and tweak from there
- Use the Data Box for quick metric lookups
- Combine with Volume Profile for auction context
