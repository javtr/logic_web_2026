## Requirements

- NinjaTrader 8 (latest version)
- Windows 10 or 11
- Internet connection for license activation
- 200 MB free disk space

## Steps

1. Download the installer from your account
2. Run the installer as Administrator
3. Restart NinjaTrader 8
4. Apply your license key
5. Verify the indicators appear in the Indicators list

## Troubleshooting installation

If the indicators don't appear after installation, see the [Troubleshooting](/docs/troubleshooting) guide.
