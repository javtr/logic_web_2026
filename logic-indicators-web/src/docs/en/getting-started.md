# Getting Started

Welcome to Logic Indicators. This guide will walk you through everything you need to start using the suite on NinjaTrader 8.

> This is a placeholder article. Edit `src/docs/en/getting-started.md` to add real content.

## What is Logic Indicators

Logic Indicators is a professional trading suite for NinjaTrader 8, focused on order flow, footprint, and volume analysis. It combines high-performance development with a focus on absorption, exhaustion, and delta.

## What you'll need

- NinjaTrader 8 installed and licensed
- A live or simulated data feed (Rithmic, CQG, etc.)
- Windows 10/11 (64-bit)
- At least 8 GB of RAM recommended
